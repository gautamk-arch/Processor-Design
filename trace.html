Each cycle shows the pipeline as the simulator's pipe command prints it after that step. An instruction that sits in EX has its operands latched; its result, flag update or branch shows up in the next cycle's state. Registers change the cycle after an instruction passes RW, and memory the cycle after it passes the memory stage.
